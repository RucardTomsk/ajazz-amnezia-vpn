Кнопка показывает состояние AmneziaVPN и переключает подключение штатной кнопкой клиента через Windows UI Automation. При свёрнутом окне работает как обычно; при скрытии в трей и выборе режима AmneziaWG получает фоновый статус его службы. Используется выбранный в Amnezia сервер; настройки VPN и ключи плагин не читает. Обновление — раз в 2 секунды.

Независимый проект сообщества, не официальный продукт Amnezia или AJAZZ.

## Установка

1. Установите и один раз запустите AJAZZ. Запустите и настройте AmneziaVPN.
2. Скачайте **AmneziaVPN-AJAZZ.zip** из [последнего релиза](https://github.com/RucardTomsk/ajazz-amnezia-vpn/releases/latest). Архив **Source code** предназначен для разработки и не содержит готового плагина.
3. Распакуйте ZIP и выполните из папки распаковки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-AmneziaPlugin.ps1
```

4. Перезапустите **только Stream Dock AJAZZ**. Перезапуск AmneziaVPN не нужен.
5. Найдите **Amnezia VPN → VPN: вкл / выкл** и перетащите на свободную кнопку.
6. Выберите протокол в настройках кнопки, сохраните настройки и нажмите **«Проверить совместимость»**. Для переключения включите флажок **«Разрешить включение и выключение VPN этой кнопкой»**. По умолчанию работает только индикация; сохранение настроек не переключает VPN.

Собирать проект и устанавливать npm/Python не требуется. Скрипт использует APPDATA текущего пользователя. Если папка плагинов у вашей версии AJAZZ другая, передайте `-PluginsDirectory "D:\путь\к\plugins"`. Для ручной установки скопируйте папку `com.rucard.amnezia.sdPlugin` из архива в каталог плагинов AJAZZ.

По умолчанию каталог установки: `%APPDATA%\HotSpot\StreamDock\plugins`. Для обновления повторите установку; предыдущие файлы сохранятся в `artifacts/backup-*` рядом с распакованным установщиком. Для удаления уберите действие с кнопок, закройте AJAZZ и удалите только папку `com.rucard.amnezia.sdPlugin` из каталога плагинов. Это не удаляет Amnezia и её настройки.

Релиз содержит `SHA256SUMS.txt`. Сравните его значение с `Get-FileHash .\AmneziaVPN-AJAZZ.zip -Algorithm SHA256`. Бинарный мост не имеет подписи Authenticode.

## Настройка

Раздел **«Настройки этого компьютера»** содержит общие параметры всех кнопок плагина. Разрешение управления задаётся отдельно для каждой кнопки. Сохранение настроек и **«Проверить совместимость»** не переключают VPN.

1. Установите и запустите AJAZZ и AmneziaVPN. Настройте сервер в самой Amnezia.
2. В плагине выберите **AmneziaWG / WireGuard**, если используете этот протокол. Для **XRay / OpenVPN — по окну клиента** оставляйте главное окно открытым или свёрнутым на панель задач. Полностью скрытое окно этих протоколов не поддерживается фоновым каналом WireGuard.
3. Путь к Amnezia обычно оставьте пустым: плагин ищет запущенный процесс без привязки к имени пользователя, диску и папке установки. При переименованном portable-клиенте или нескольких установках укажите полный локальный путь к нужному `.exe`. Плагин не запускает этот файл автоматически.
4. Русский и английский интерфейс распознаются автоматически. Для другого языка задайте обе подписи главной кнопки: при подключённом VPN и при отключённом. Например, немецкие `Verbunden` / `Verbinden`.
5. При медленном ответе компьютера увеличьте ожидание с 5 до 10–20 секунд. Нажмите **«Сохранить настройки»**, затем **«Проверить совместимость»**.
6. Если клиент найден и состояние определяется, разрешите управление нужной кнопкой.

Режим **«Авто»** подтверждает активный AmneziaWG, но не делает вывод «VPN выключен» только из отсутствия туннеля WireGuard: в этот момент может работать другой протокол. Для полного цикла из трея явно выберите AmneziaWG / WireGuard.

Диагностика показывает найденный клиент, его версию, среду AJAZZ, состояние окна и доступность штатной кнопки без вызова команды. Если новая версия клиента изменила внутренние идентификаторы кнопок, потребуется обновление плагина.

## Индикация

| Значок | Значение |
| --- | --- |
| Зелёный щит с галочкой, ВКЛ | Клиент сообщает «Подключено» |
| Серый щит с чертой, ВЫКЛ | Клиент сообщает «Отключено» |
| Жёлтый щит, ЖДИТЕ | Подключение, отключение или ожидание подтверждения |
| Красный щит, ОШИБКА | Ошибка клиента либо истёк срок подтверждения команды |
| Щит с ?, ? | Достоверное состояние недоступно, управление заблокировано |
| Перечёркнутый щит, НЕТ APP | AmneziaVPN не запущена |

`R` рядом с надписью означает режим только индикации. Это статус клиента, а не проверка доступности интернета или прохождения всего трафика через VPN.

## Совместимость и ограничения

- Windows 10/11 x64, .NET Framework 4.x (системный), AJAZZ с Node.js 20 в составе программы. Отдельный Python или Node.js для использования плагина не нужен.
- Целевая проверенная версия клиента: AmneziaVPN 4.8.19.0; русский и английский интерфейс. Для других языков есть настройка подписей; другая структура интерфейса в новых версиях может потребовать обновления плагина.
- AmneziaVPN должна быть запущена. Плагин не запускает клиент автоматически, чтобы не вызывать его автоподключение.
- Окно можно свернуть на панель задач. Также поддерживается скрытие в трей с протоколом AmneziaWG / WireGuard и соответствующей настройкой плагина: статус читается напрямую из локальной службы без показа окна. Этот фоновый канал относится именно к WireGuard, а не к XRay/OpenVPN.
- Для управления оставьте главную вкладку выбранной перед скрытием. При нажатии кнопки плагин обращается к штатному механизму открытия Amnezia, вызывает её кнопку и возвращает окно в трей. Окно может кратковременно появиться при переключении. Само наблюдение окно не раскрывает. Переход в настройки клиента может потребовать возврата на главную вкладку.
- Оба приложения запускайте с одинаковыми правами. Не требуется запускать плагин от администратора.
- Повторные нажатия блокируются во время операции. Команды не повторяются автоматически при таймауте. Успешное подключение подтверждается чтением состояния клиента.
- На запуске, при установке, смене страницы и выходе из AJAZZ команды управления VPN не отправляются.

Проверенная конфигурация: AJAZZ 3.10.200.0420, устройство AKP153R, AmneziaVPN 4.8.19.0 и AmneziaWG v2. Полный цикл подключения и отключения проверен с открытым, свёрнутым и скрытым в трее окном. Переключение XRay/OpenVPN и другие сочетания версий не подтверждены.
