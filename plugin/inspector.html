Только индикация: нажатие не меняет подключение.

Проверка совместимости не переключает VPN и не открывает его окно.
Настройки этого компьютера Общие для всех кнопок Amnezia VPN. Сервер и ключи настраиваются в самой Amnezia.

Нужен только если автопоиск не находит клиент или запущено несколько копий. Полный путь без кавычек. Клиент не запускается автоматически.
Другой язык или медленный компьютер

Русский и английский распознаются автоматически. Для другого языка скопируйте обе подписи главной кнопки точно как в Amnezia.

Увеличьте до 10–20 секунд, если проверка сообщает, что клиент не успел ответить.
Зелёный щит — VPN включён; серый — выключен; жёлтый — переключение; ? — состояние не определено. R означает режим только индикации. Для управления оставьте главную вкладку Amnezia выбранной перед сворачиванием. Проверенная система: Windows 10/11 x64, AJAZZ с Node.js 20 и AmneziaVPN 4.8.19.0. Изменение внутренних элементов в другой версии клиента может потребовать обновления плагина.
