# Amnezia VPN for AJAZZ — 1.2.0

Первый публичный выпуск / First public release.

Кнопка AJAZZ показывает состояние AmneziaVPN и включает/выключает подключение.
Добавлены настройки протокола, пути, языка и времени ожидания, а также
диагностика совместимости без переключения VPN. Лицензия MIT разрешает
использование, изменение и распространение, в том числе коммерческое.

## Install / Установка

Download **AmneziaVPN-AJAZZ.zip**, extract it, start AJAZZ once, then run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-AmneziaPlugin.ps1
```

Перезапустите AJAZZ, добавьте действие Amnezia VPN на кнопку, выберите свой
протокол и нажмите «Проверить совместимость». Управление включается отдельно
флажком в настройках кнопки. AmneziaVPN должна быть запущена и настроена.

Requires Windows x64, .NET Framework 4.x and AJAZZ with Node.js 20 support.
Tested with AJAZZ 3.10.200.0420 / AKP153R and AmneziaVPN 4.8.19.0 / AmneziaWG v2.
No separate Node.js, npm or Python installation is needed for end users.

## Verification

- 21 automated JavaScript tests and 19 C# state/validation checks.
- Live disconnect/reconnect cycles tested during development with visible,
  minimized, and tray-hidden AmneziaWG windows.
- Portable archive installation, settings persistence and read-only diagnostics tested.
- Physical second-PC compatibility and XRay/OpenVPN live switching are not verified.
- Tray-hidden background status requires AmneziaWG / WireGuard mode. For other
  protocols keep the main client window open or minimized on the taskbar.

See the repository's VERIFICATION.md for scope and limitations. Binaries are
unsigned. Compare `Get-FileHash .\AmneziaVPN-AJAZZ.zip -Algorithm SHA256` with
the attached **SHA256SUMS.txt** before installation.
