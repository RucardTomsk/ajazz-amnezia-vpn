# Amnezia VPN for AJAZZ — 1.2.1

Исправлено определение состояния при автозапуске AmneziaVPN сразу в трей:
для AmneziaWG / WireGuard больше не требуется один раз открывать окно клиента.
Плагин опрашивает службу, даже когда главное окно ещё недоступно через UI Automation.
Если служба запускается с задержкой, опрос повторяется автоматически.

Fixes AmneziaWG status detection before the client's first window display.
Monitoring does not open the window or switch the connection. An explicit key
press can initialize the UI using the client's existing second-instance channel.

## Update / Обновление

Download and extract **AmneziaVPN-AJAZZ.zip**, run `Install-AmneziaPlugin.ps1`,
then restart AJAZZ. Select **AmneziaWG / WireGuard** in the key's settings.
No Amnezia restart or VPN reconnection is required for installation.

## Verification

- Windows regression test runs the compiled bridge against a test process with
  no application window, then verifies simulated connected/off/transition states.
- Service startup delay, automatic recovery and UI-only mode isolation are covered.
- Existing controller and state-parsing regression tests remain enabled.
- Full Windows reboot and live VPN switching are not part of this patch's automated checks.

XRay/OpenVPN tray-hidden state remains unsupported. See README for compatibility.
The release includes **SHA256SUMS.txt**; binaries are not Authenticode signed.
